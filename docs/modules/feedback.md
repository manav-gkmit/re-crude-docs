# Feedback Collection & Formatting

This document describes the **Feedback Collection & Formatting** module in Re:Crude, which automates the gathering, normalization, and storage of interview feedback.

---

## Responsibilities

The Feedback Collection & Formatting module is responsible for:

- **Collect Interviewer Feedback**  
  Gather feedback from interviewers via Slack, Email, or other integrated channels.  

- **Normalize Using LLM**  
  Convert unstructured free-text feedback into a **structured, standardized format** using Large Language Models.  

- **Save Structured and Raw Feedback**  
  Store both the normalized feedback and the original text for auditing, traceability, and future reference.  

- **Update Zoho ATS**  
  Push structured feedback back to Zoho ATS, updating candidate profiles and interview status automatically.

---

## Key Benefits

- Ensures **consistent evaluation criteria** across all interviewers.  
- Reduces **manual effort** in processing and entering feedback.  
- Enables **auditability and traceability** of interviewer comments.  
- Integrates seamlessly with the **LLM evaluation and batch processing pipeline**, maintaining a smooth end-to-end recruitment workflow.

---

By implementing this module, Re:Crude ensures **timely, structured, and actionable interview feedback**, improving both recruiter efficiency and hiring decision quality.
