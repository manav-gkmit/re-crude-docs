# Project Overview

Re:Crude is an internal recruitment automation platform designed to reduce manual hiring effort and improve evaluation consistency.

## Objectives
- Automate resume screening
- Standardize interview feedback
- Improve hiring turnaround time
- Maintain traceability across candidate lifecycle

## Integrations
- Zoho ATS (candidate lifecycle)
- Slack & Email (communication)
- LLM Provider (evaluation & formatting)
